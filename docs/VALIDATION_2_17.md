本版修改首页完成后的重复发送保护，以及日历天气、便签的编辑与首页预览衔接。NFC 协议和照片算法没有作为本次功能进行替换。

## 自动检查

主机检查入口：`tests/run_java.py`，本版已执行通过。保留现有协议、图像打包、InkSight 参考夹具、照片场景、日历、轮播状态等回归，并增加 CardScene 与 PushReceipt 的纯 Java 状态测试。其中包括 24 项协议用例、CardScene 的32组完整往返及损坏状态检查、完成记录的内容/屏幕区分与恢复，以及 InkSight 的34项参考检查（859582像素）。

原生检查入口：`tests/android/build_card_tests.py` 编译测试 APK；`CardRendererInstrumentation` 在设备上执行。新增或更新的检查包括：

- 成功后的首页按钮不可发送，直接调用发送函数也受保护。
- 恢复前台和相同内容重新生成不会解除完成状态；重发需要菜单操作与明确确认。
- 已完成照片切到原图对比后，从菜单确认重发会调用假的 Host.send，并先将首页恢复为同一快照的最终四色预览。该补充用例仅编译检查，尚未在设备执行。
- 日历、便签编辑器的取消不修改原稿；完成返回独立场景和固定的四色预览，不发送 NFC。
- 天气采用手动输入与离线模拟回调检查，测试不请求网络。
- 首页始终传输所见预览对应的快照；上传100%和停止请求均不提前结束本轮通信状态。

本版原生测试 APK 已编译、签名并通过签名验证；尚未在 Android 设备执行。测试涉及的偏好设置会保存并恢复，照片缓存不被替换。发送使用假的 Host，天气通过离线回调注入，不连接 Shizuku、请求 Root 或操作 NFC。测试 APK 编译成功不表示原生布局、渲染或这些交互用例已经运行通过。
