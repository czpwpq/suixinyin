# 随心印 2.20-test1 · 单 App 内置激活

本版加入本机无线ADB配对及随心印专用授权服务。**只安装随心印，也有一条完整的免Root激活路径**；不需要另装Shizuku管理器。首次仍须在系统开发者选项开启无线调试，并由你完成配对授权。没有绕过系统授权，也没有静默自提权。

原照片/日历/便签/每日内容/阅读继续保留，底部仍为照片、阅读、设备、日志。内置激活同时提供照片与阅读后端；激活成功本身不寻卡、不传图、不刷新屏幕。

## 首次使用（建议通知栏配对）

1. 覆盖安装本版，进入「设备 → 内置激活 · 无需另装 Shizuku」。不必先卸载旧版应用。
2. 手机连接Wi-Fi，在系统开发者选项开启无线调试。小米如提示ADB权限受限，核对「USB调试」与单独的「USB调试（安全设置）」；已有可用设置不必清除。
3. 在随心印点击「通知栏配对」，按需允许本App发送配对通知。此通知权限仅供这条配对入口；也可使用下方手动配对。
4. 点击打开无线调试设置，选择「使用配对码配对设备」。**保持系统配对窗口打开**，展开通知，在随心印的通知中输入窗口里的6位码。通知只查找本机配对服务，发现窗口约2分钟，失败可重新开始。
5. 通知提示配对成功后回到随心印。在无线调试首页查看「IP地址和端口」中的**连接端口**，填写或点击发现本机服务，然后点击「激活并使用内置连接」。
6. 等待「内置激活成功」，返回照片或阅读页使用原推送/连接按钮。只有这时才按你的操作开始NFC任务。

**配对端口与连接端口不是同一个。** 前者来自6位码的弹窗，后者来自无线调试首页；重新打开无线调试后端口可能变化。App只连接127.0.0.1，自动发现也只接受本机地址，不需要填写局域网其他设备IP。

## 手动配对

如果不想开通知，可把系统设置和随心印分屏：保持配对码弹窗打开，在App填写配对端口及6位码，点配对。成功后再使用无线调试首页的连接端口激活。

部分系统在切换页面时会关闭配对码弹窗；窗口关闭后原码/端口可能失效。这种情况使用通知栏或分屏完成配对，不要一直重试已经失效的码。

## 后续启动与停止

- 配对身份密钥保存在本App私有、排除备份的目录中，通常无需每次重新配对。配对码不存储、不写日志；清除应用数据或在系统撤销配对后需重新配对。
- 手机重启、App进程被完全结束或服务失效后，需要回到内置激活页，使用当前连接端口重新激活。只关闭/重建某个Activity不会主动停止已经成功的服务。
- 激活尚未完成时离开激活页面，会取消本次激活；晚到的服务不能把已取消请求改成成功。通知栏配对可在短时间内后台完成。
- 「停止」会取消当前配对/激活、服务发现和通知，并关闭本App的内置授权服务；不会自动重启服务或重发图片。NFC正在通信时先等待有界清理完成。
- 内置服务只供随心印使用，不替其他App提供Shizuku授权。

## 保留的备用方式

「设备 → 连接与授权」可切换「内置激活 / 外置Shizuku / Root」。本版默认内置方式；旧的直接Root选择保留。选择外置Shizuku后沿用以前的启动、授权、身份校验流程。

照片支持直接Root；阅读支持内置激活和外置Shizuku。阅读的离开暂停、手动重连及音量上下翻页规则延续2.19。授权后端变化不会改变原厂驱动或把全局刷新变成局刷。

Android11以下没有本版无线配对入口，可使用原有备用方式。NFC控制器/固件不支持Q-Poll或供电不足的问题，也不会因内置激活而消失。

## 测试与反馈

本机已构建APK及原生测试，但没有连接你的小米17 Pro和手机壳。首次请按下面顺序验收：

1. 使用内置方式完成配对，确认系统已配对设备出现随心印相关身份，并等待App身份校验成功。
2. 回首页推一张已验证可用的图片，确认实际画面和按钮完成状态。
3. 进入阅读，明确点击连接，测试音量上下翻页和下一页预传。
4. 停止内置服务后，确认不能继续发送；重新激活后可恢复。切换外置Shizuku备用方式也应正常。
5. 完全结束App后重开，确认显示未激活，使用当前连接端口重新激活。不要把配对成功当成内置服务已经启动。

失败时点击激活页的「诊断」复制文字；记录包括Android版本、应用UID和阶段/启动错误，不包含6位码、私钥或启动nonce。配对/连接端口需随当前系统界面核对。无需发配对码。

本版不承诺每一台小米均能激活；真实TLS/SPAKE2配对、系统Binder交付、厂商NFC和实屏刷新仍需手机确认。源码与APK已保留依赖许可，GitHub仍未发布。
