# 2.12-test1 使用与真机验收

本版可覆盖之前的“墨水屏便捷版”2.11，不会替换原作者 App。安装后确认 A0/A1 实物类型及 Shizuku 连接。

## 拍立得 / 自由构图

1. 在“图像与发送”顶部选择“拍立得 / 自由构图”。可点“重新选图”。
2. 下方照片区域单指移动、双指缩放；滑杆任意角度旋转，也可90°旋转或重置。
3. 选择相框开关、白边宽度、原图/黑白/暖色风格、题字与颜色。
4. “应用到预览”只生成画面，不发送。回到主界面选择色彩映射和抖动，再确认发送。

## 便签 / 日历 / 时钟

- 便签支持换行、字号、粗体、四色字体/底色/描边。长文本缩小或省略，发送前检查最终预览。
- 日历为周一开始的公历月历；“选择月份 / 标记日期”选择一个日期，显示其所在月份并标记该日。
- 时钟使用手机当前时区，数字/指针可切换，不显示秒。手动“应用”生成静态快照。
- 时钟编辑页可选择“开启时钟定时刷写”，再选间隔并确认。不是准点报时；每次刷新完成后开始下一段等待。

## 抖动与照片

“抖动处理”开启后选择算法和强度。照片可从“实验暖调 + 蛇形 Floyd–Steinberg + 75%”开始对照；插画可比较感知色彩和有序 Bayer。不同照片结果不同，不能仅凭算法名称判断实屏最佳。

文字卡片应用时会复位照片增强、关闭抖动并使用感知映射；纯四色像素保持不变。黑白二值化和色块简化仍走原有处理，新四色抖动只用于原始细节模式。算法关闭或强度0不进行抖动。

## 多图轮播

1. “多图轮播 / 定时刷写”中选择最多30张图片。新列表会替换旧列表，图片复制到App私有存储；无需长期访问原相册路径。
2. 调好主页面处理参数，再选间隔1分钟、5分钟、10分钟、30分钟、1小时、6小时或24小时并确认开始。
3. 首轮立即开始。每轮刷屏完成后再等指定间隔；不会同时开启两个写入，也不会补刷错过的时间。
4. 保持手机解锁、App前台和NFC贴合。停止按钮可终止等待或请求停止当前通信。离开、锁屏、失去授权、目标改变、读取失败、刷屏失败或结果未确认均需手动重新开始。
5. 轮播运行状态不跨App重启保存；已导入的图片列表会保留，可手动清空。

## 建议验收顺序

- [ ] 覆盖安装成功，Shizuku自动连接，原来的手动只读/刷屏不回归。
- [ ] 四种创作模式均能打开、修改、返回、应用；预览比例正确。
- [ ] 拍立得缩放/拖动/旋转后，应用的内容与编辑预览一致；无框照片不额外裁切。
- [ ] 便签的黑白、红黄、描边及长中文预览正确；日历六行月份不截断。
- [ ] 同一照片对比各算法，关闭抖动与强度0无散点，精确四色测试图不变色。
- [ ] 先手动写入便签，再测试两张图以1分钟间隔轮播两轮。
- [ ] 等待中停止不再刷写；刷写中停止等待当前通信返回，不重发刷新指令。
- [ ] 离开、锁屏、Shizuku停止、移开屏幕、换另一块屏幕后不自动继续。
- [ ] 时钟手动/定时均显示手机时区；移开手机后画面静止属于预期。

## 可选开发者原生渲染测试

源代码提供无需额外测试框架的独立测试APK。设置 `JAVA_HOME`、`ANDROID_HOME` 后先构建主APK，再运行 `python tests/android/build_card_tests.py`。

安装主APK及测试APK后，按 `tests/android/AndroidManifest.xml` 中的 instrumentation 名称运行 `adb shell am instrument -w org.nfcresearch.qpolllab.cardtests/org.nfcresearch.qpolllab.CardRendererInstrumentation`。检查PASS以及导出的PNG后，才能将原生渲染测试标记通过。

这些测试不替代NFC实屏验收。分享反馈时附App版本、系统版本和操作步骤；公开日志前移除设备标识，原始私人照片不放进GitHub仓库。
