# 随心印 2.19-test1 · TXT 阅读与刷新对照

主导航为「照片 / 阅读 / 设备 / 日志」。照片、卡片与首页推送流程延续上一版；阅读书架、按钮和默认阅读页使用相同的灰白黑样式。此包可覆盖安装2.18-test3，保留原包名、签名及已有草稿，不必卸载清数据。GitHub尚未发布，图库继续暂缓。

## 导入与阅读

1. 点击「阅读 → ＋ 导入 TXT」，可多选文件，也可分批添加。每本上限32 MiB，支持UTF-8、带BOM的UTF-16及GB18030；内容重复会提示已有书籍。文件复制到应用私有书库，原TXT不改动。
2. 点击书籍打开阅读，书架可按最近阅读或书名排序；长按删除只清除本机书库副本和对应进度/书签。
3. 点击正文左右区域或「上一页 / 下一页」翻页；**音量下键下一页，音量上键上一页**。只在阅读页前台生效，长按不连续触发，输入框中不拦截音量键。
4. 支持目录、搜索、书签和进度记忆。搜索按需读取章节，最多展示200条；超长章节按块加载，避免一次把大书全部交给排版器。
5. 「阅读设置」可改字号、字体、行距、页边距、亮度及纸白/夜间/护眼显示。改排版后按字符位置重新定位，页码可能变化。

普通手机阅读离线可用，不需要Shizuku。电子墨水屏的阅读页面为硬黑白输出，不对小说文字做四色抖动。

## 墨水屏阅读

先在「设备」选择与实物一致的A0或A1，并保持Shizuku运行及本应用已授权。阅读设置同步此屏幕选择；未确认类型时不发送。当前阅读NFC后端使用Shizuku，设备页的Root选项仍用于原照片/检测链路。

在正文页把手机与墨水屏贴稳，再点击「连接墨水屏」；连接成功会把当前页写入屏幕。刷新完成后预传下一页，接下来按音量键或界面按钮翻页。预传仅传输数据，下一次确认翻页才触发显示更新。

快速连点时保留最后想去的页，当前物理刷新完成后再处理；不会并行发送多个刷新命令。预传页与目标像素完全匹配时使用预传，回翻或跳章不命中时完整传图。任何失联/异常都停止本会话，不自动重复刷写。

「息屏翻页」是保持应用前台的黑屏覆盖层，不是安卓锁屏。触摸可退出覆盖层；返回书架、打开目录/搜索/设置、切后台或锁屏会暂停NFC会话，回来后需手动连接。请保持贴合供电，不能把无源手机壳当作能脱离手机连续刷新的独立阅读器。

阅读与原照片后端共用互斥会话锁。离开阅读后若立即推送照片提示“会话正在释放”，稍等后明确重试，不会替你自动发送。

长按正文页的连接按钮可查看/复制阅读诊断，点击状态文字也可复制。记录包括目标、阶段、压缩字节数/包数、D4刷新耗时与翻页总耗时，不包含小说正文。

## 先测提速，再判断局刷

从「阅读 → 阅读设置 → 刷新对照测试」进入：

1. 贴稳并连接，点击「① 显示 A」，等到完成。
2. 点击「② 预传 B」，实体屏应仍显示A；待提示已预传。
3. 点击「③ 显示 B」。这一组仅中心A/B字样变化，边框和四色角标保持同样像素。录视频观察固定边框是否参与闪烁，记录画面是否完整。
4. 点击「复制测试记录」。把记录和实拍视频一同反馈，可分辨传图阶段与屏幕刷新阶段哪个耗时更长。

这两个路径均执行**板内原厂全局刷新**：①普通D3传图+D4；③命中预传后D4-only。真实LZO压缩、预传及较短等待可减少传输等待，但不改变原厂波形。固定边框不闪或速度变快，都不能单独证明局刷。

当前没有已验证、无需覆盖原厂驱动的局刷参数，因此不提供“每5–10页全刷”伪开关。测试页不写DA/DB、不探测未知D4位。参考协议项目的A0/A1分段刷新会改写配置，且不能保证窗口外画面保持不变；现有公开资料不足以把它作为阅读器局刷直接启用。需拿到匹配面板与驱动板的有效局刷/差分波形和命令，再单独实现并验收。

## 本次验收清单

- 覆盖安装后原照片、文字、相框、日历与天气仍能预览和推送；完成状态不会误触重传。
- 导入中文UTF-8和GB18030各一本，跨章节翻页、重开进度、搜索与书签正常。
- 音量上下各翻一页，长按不连发；退出阅读后系统音量恢复正常用途。
- 先测当前页，等下一页预传就绪再翻页；再回翻、跳章，确认屏幕与手机所选页一致。
- 刷屏中切后台/离开或移开手机，确认停止，不自动重发；重连后由用户明确继续。
- 运行A/B对照，反馈普通/命中预传的日志和视频，尤其D4到刷新结束的时间。

本机只完成主机测试与APK/原生测试构建，没有连接你的小米17 Pro及手机壳。真实UI、厂商NFC、锁权限和实屏耗时仍需上述手机验收。
