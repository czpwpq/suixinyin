# 随心印 2.20-test2 · 修复通知配对与设置切换

本版对应真机反馈的两个问题：通知停在等待端口且没有输入按钮；系统设置压入随心印的任务，配对弹窗打开后难以切回。

## 这次改动

- 通知无论是否发现端口，都显示输入动作。正文不再跳回App；需要展开通知，点击下方明确的输入按钮。
- 自动发现到配对端口时，可只填6位配对码；未发现时，可直接在通知里填「配对端口 空格 6位码」，例如`37123 012345`。这是格式示例，请使用系统当前弹窗的实际数字。
- 通知中另有「打开无线调试设置」按钮。App和通知都用独立系统任务打开设置，不清除已有设置任务栈；最近任务中可以切换系统设置与随心印。
- 发现/输入/配对期间使用用户主动开启的限时前台服务，结束、取消、超时都会停止，不永久保活、不自动重启或刷屏。
- 修复服务类型格式兼容、解析失败无法重试、解析队列卡住、多地址与地址后续更新处理；增加脱敏阶段诊断，仍只连接本机127.0.0.1。

## 推荐操作

1. 覆盖安装2.20-test2，打开「设备 → 内置激活」。
2. 点击「开始通知栏配对」，允许通知，然后点击「打开无线调试设置」。保持手机连接Wi-Fi且无线调试已开启。
3. 在系统设置点击「使用配对码配对设备」，保持弹窗打开。
4. 下拉并展开随心印通知，**点击下方「输入配对码」或「输入端口和配对码」按钮**，不用点击通知正文，也不用切回App。
5. 如通知尚未发现端口，把弹窗中「IP地址和端口」最后的配对端口与6位码一起填写，中间空格。例如系统显示`192.168.1.3:37123`及`012345`时，填写`37123 012345`，不填IP地址。
6. 配对成功后返回随心印，使用无线调试首页的**连接端口**，点击激活。连接端口与刚才弹窗的配对端口不同。

如果通知输入格式不对，会继续保留入口供修改。系统配对窗口关闭/重新打开后，请使用新的端口和码。配对成功仍不等于服务已激活；需要完成第6步并看到身份校验成功，再去照片或阅读页操作。

## 测试重点

- 通知还在等待端口时，展开后是否已经有输入按钮。
- 打开系统设置后，最近任务中是否可切回随心印；尽量在通知完成输入，避免关闭系统配对弹窗。
- 自动发现未成功时，使用「端口 空格 6位码」能否完成配对。
- 配对、激活成功后，再确认照片推送与音量翻页正常。
- 取消或超时后，限时前台服务及配对通知应退出，不能自动刷屏或重试。

如仍失败，复制「查看 / 复制激活诊断」里的文字。新增诊断可区分服务未发现、解析失败、地址过滤和实际配对失败；不要发送配对码。

这次本机执行了主机回归和APK/原生测试构建，没有连接目标小米，不能把编译结果视为HyperOS通知、设置任务及真实配对已通过。第一次使用的权限、重启后激活规则及备用方式见[2.20基础说明](GUIDE_2_20.md)。
