# 随心印 2.15-test2 · 预览遮挡修复

打开风格、留白文字或更多选项后，整张预览会缩小显示在上方，工具显示在下方独立区域，不再盖住图片。参数只在工具区滚动；点击“收起”恢复大图。底部状态与发送按钮保持固定。

拍立得流程仍为：选图 → 构图 → 四色预览与发送。调色、抖动、留白和文字改变后会更新最终四色快照，生成期间暂时不能发送旧快照。仅点击最终预览页的发送按钮才发起刷屏。

工具打开时会暂时收起重复的步骤提示与摘要，腾出空间给预览和参数。手机字体较大时，工具区仍可单独滚动。便签、日历天气和时钟采用同样布局。

本版包名 org.nfcresearch.qpolllab.easy，版本号22，和上一版同一签名，可覆盖安装。手机中的照片、授权与 NFC 刷屏需要实际验收；原生 UI 测试只编译，不能视为已在手机运行通过。具体检查结果见 VALIDATION_2_15_TEST2.md。尚未发布 GitHub。
