# 随心印 2.18-test1 · 照片编辑修复与每日内容

## 先验证照片编辑修复

上一版的文字和相框报错为 `Immutable bitmap passed to Canvas constructor`：装饰阶段将不可修改的像素位图作为绘图目标。本版新建应用自己的可修改 ARGB_8888 画布，再写入照片像素并绘制装饰。原始照片和编辑参数不被改写。

覆盖安装后，先在照片里分别试加一段中文、多行文字及不同相框，再试横版、镜像和旋转。点完成回首页查看最终预览，再手动推送。

## 新入口和统一流程

日历与天气、便签下方新增两行入口：今日历史 / 科技与 AI 简报、每日语录与书籍 / 二次元生日。推送按钮仍固定在底部。

1. 进入一种内容，点“获取内容”。仅此操作或明确选择人物时发起相应查询。
2. 选择条目、模式和展示数量。历史与简报可从所选条目起展示1–3条；1条大字详细、2条简洁、3条标题速览。
3. 可在“文字”页修改标题、正文、署名；生日可修改作品名。手动改写会显示提示，须自行核对。
4. 点顶部“完成”，仅回到首页展示固定四色预览。
5. 核对预览后再点首页推送按钮。完成后按钮锁定；重发仍须通过顶部更多菜单明确确认。

取消编辑不替换首页原内容。每种卡片分别保留最后一次完成的本地草稿与已获取画像；再次打开不会自动联网、更新日期或发送。

## 内容与来源

| 功能 | 本版内容 | 日期和使用边界 |
| --- | --- | --- |
| 今日历史 | 60s API 转供的历史事件，来源百度百科；事件优先展示 | 可选月日；沿用来源记录，不把人物生卒和事件混称为热度排名 |
| 简报 | IT之家科技实时榜、AI工具集资讯摘要，可切换科技 / AI / 合并 | 科技榜只有获取时间；AI按所选日期严格匹配，没有当日内容就提示暂无，不回填昨天 |
| 每日 | 一言随机语录、11部本地轮换推荐书单 | 语录署名按来源显示，缺署名不猜作者；书单推荐理由为编辑文字，非销量榜或作者原话 |
| 二次元生日 | AniList 当日生日角色、多人物选择、画像与关联动画作品 | 仅支持获取今天，按月日复核；作品名保留来源原文，名单可能不完整 |

生日在主动获取名单或选择人物后加载所选画像，失败仍保留可编辑的姓名、生日和作品，可点“获取所选人物画像”重试。不会把上一位人物的画像留给新选择。无画像时显示占位。画像区域单独使用 InkSight，文字和色块直接绘制为四色，正文最低22px。

本版“AI简报”是来源提供的资讯摘要，没有连接生成模型，不将其标为模型独立分析的“AI洞察”。若之后需要生成分析，可再接入用户选择的模型服务。

有来源链接的条目可点“查看原文”。原始日期、来源和获取时间均保留在草稿与卡片中，旧快照不会因重新生成预览而变成“今日新数据”。

## 内容服务设置

编辑器“内容源设置”可填写兼容60s API的 HTTPS 根地址，影响历史和简报。默认公共服务用于个人测试，官方明确有严格限额，正式发布应自部署或选择有使用授权的服务。生日和语录分别使用 AniList、Hitokoto，不跟随此根地址。

只在主动获取或选取生日人物时联网，不上传照片、便签或卡片草稿。请求有超时及响应大小限制，限流、断网或失败不自动重试；取消会使旧回调失效。无需额外 Android 权限或模型密钥。服务可能暂时无数据或无法访问，手机网络情况需单独确认。
