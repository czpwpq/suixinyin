# 1.0.1-test1 · 关闭重开后的自动连接修复

本版针对“首次激活传图成功，关闭 App 再打开又要求走配对流程”。包名与正式 v1.0.0 相同，沿用原签名，versionCode 34；可以覆盖安装，保留照片草稿、书库和原本机配对身份。

## 使用

1. 覆盖安装后保留系统无线调试开启，直接打开随心印。
2. 已有本机身份时，首页会显示“连接中”；恢复并核验完成后显示“已连接”。再手动推送照片或连接阅读屏幕。
3. 完成一次连接后，退出/清理 App 再打开，检查能否再次自动恢复，无需重新输入配对码。

首次从 v1.0.0 覆盖时，上个版本尚未保存连接端口，本版会先自动发现。系统如果无法提供自动发现，只需打开“内置激活 → ③ 手动连接端口（备用）”，填写无线调试首页当前的连接端口，成功一次后本版会记住。已有配对通常不必再操作①②。

## 改动

- 沿用本机私有目录中的 ADB 密钥和证书，兼容旧版已有身份，不生成新身份来代替已有配对。
- 打开首页、阅读页或内置激活页时，在前台尝试一次自动恢复；优先使用本机新发现的连接端口，上次完整核验成功的端口作为回退。
- 自动恢复只连接本机 127.0.0.1，最多尝试三个不同端口，整个回合有时间上限。切换页面保留短暂交接宽限，离开 App 后停止自动恢复。
- 刚关闭再打开、旧授权服务还在释放时，会短暂等待清理完成后再恢复。
- 已有身份的激活页优先显示免配对码“重新连接”，首次①②步骤折叠；可明确展开重新配对，③手动连接仍保留。
- 连接恢复后，主页重新校验后端身份并更新连接状态，不恢复旧推图请求，不自动开始 NFC/阅读刷写。
- 明确“停止内置服务”会暂停后续自动恢复，手动点重新连接或激活后可继续使用。
- 普通断网、端口变化或无线调试未开启不会删除密钥，也不会直接要求重新配对；当前发现的服务确实拒绝身份且候选耗尽后，才显示重新配对提示。

原来的完整 UID、安装 APK 路径、编译后端版本、nonce 和三个 Binder 核验继续保留，启动 ADB 断开后仍复验。没有改变 NFC 传输协议、图像算法、原厂刷新波形或局刷能力。

## 系统边界

手机重启、系统自动关闭无线调试、系统撤销配对或用户清除应用数据后，仍须处理对应系统设置。App 不能自动打开系统无线调试，也不能替系统重新授予已撤销的配对权限。关闭 App 本身不会清除已经保存的密钥。

此版是本地构建测试版。维护端的主机/模拟边界回归与编译检查不能代替目标小米手机的实际关闭重开验证。
