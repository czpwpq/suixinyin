# 2.13-test2 验证记录

本版为后端身份检查和连接恢复测试版。包名继续为 `org.nfcresearch.qpolllab.easy`，`versionName=2.13-test2`、`versionCode=19`；使用原便捷版签名覆盖升级，不要求卸载清数据。

## 用户反馈与已知证据

- test1 日志在 NFC 通信开始前出现 `SecurityException: Wrong caller`。
- 用户提供的只读诊断中，Android 用户为 0，当前进程 UID 与安装 UID 均为 10329；Shizuku 权限已允许，应用收到有效 Binder。
- 上述信息证明了当前应用侧的身份一致性；当时后端实际解析的 UID、APK 来源及残留服务身份仍需进一步核对，不能据此宣称根因已经确定。
- 用户另提供 test1 界面展示 Open-Meteo 天气数据的截图。该截图可作为 test1 天气界面与获取数据路径的反馈，不能推断 test2 后端、NFC、手势或全部天气异常路径已经验证。

## 本版实现与验证目标

- 编译后端版本提升到 20，UserService 服务标记按当前应用 UID 隔离。
- 后端从传入的 Android Context 解析本应用身份，不固定查询 Android 用户 0。
- 新增只读 INFO 握手，在显示已连接前核对应用包名、当前安装 UID、协议版本、编译后端版本、后端进程 UID 和 APK 路径。
- 操作事务保留严格调用方 UID 校验；不匹配时输出足够的身份诊断并停止，不通过放宽 UID 检查恢复通信，不自动重放先前写入。
- 先验证不贴手机壳时的连接 / 身份检查，通过后再做硬件只读及手动刷新。照片、日历、天气和 NFC 协议能力仍沿用本系列原有路径。
