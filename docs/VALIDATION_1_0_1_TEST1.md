# 1.0.1-test1 验证记录

2026-10-26。versionCode 34，编译后端身份 35，沿用公开 v1.0.0 的包名及签名。修复范围为内置激活在重新打开 App 后的恢复、状态展示及入口。

## 根因及实现

旧版已将 ADB 私钥及证书持久化，但内置后端与 App OWNER Binder 同生存周期；进程结束会停止后端，重新打开又只检查内存 Binder，没有自动重新激活。旧连接端口也未持久化。

本次保留 OWNER 死亡后结束后端的机制，前台使用已有身份执行有界自动恢复。只有全部服务核验成功后保存连接端口；优先本机 NSD 新端口，缓存作回退。旧 v1 身份文件可直接迁移，不依赖新增“已配对”标记。确认后台、切换后端和手动停止均会取消恢复，停止状态持久化。普通网络/端口失败不删除身份；旧缓存端口的 TLS 错误不会直接持久化“需要重配”。

恢复完成只通知主页重新核验照片 Binder，不执行旧推图回调、不自动开始 NFC 或阅读会话。原来的 nonce、full UID、安装 APK、服务编译版本、三个 Binder 及启动 ADB 断开后复验继续保留。
