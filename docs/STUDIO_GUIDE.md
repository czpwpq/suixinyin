# 随心印 2.14-test1 使用与测试

此版将“墨水屏便捷版”改名为“随心印”。包名仍是 `org.nfcresearch.qpolllab.easy`，使用同一签名，覆盖安装保留原有设置和 Shizuku 授权。versionCode 为 20；原版应用仍与本版分开。

## 首页与设置

首页采用暖米白、森林绿与暖棕色，保留四个入口：拍立得、便签、日历与天气、热门图库。右上角齿轮进入设置，三个分页保留原有设备与授权、图像参数、高级参数，运行日志、屏幕类型、NFC 检测、时钟、轮播和许可证均可在这里找到。

拍立得、便签、日历仍在同一创作页调整、查看最终四色预览并确认发送。图片构图区域显示原图，上方预览显示实际发送的四色像素。选择 A0/A1 后再发送；手机需保持解锁、前台及 NFC 贴合。

Shizuku 后端保留身份握手，后端版本提升为 21；只有核对包名、完整 UID、实际调用 UID、后端身份和 APK 路径后才显示“身份已验证”。仍需在目标小米 17 Pro 上核对上一版 Wrong caller 是否已解决。

## 多图轮播

入口位于拍立得的“我的轮播图库”，以及齿轮内的轮播管理。

1. 点“继续添加 · 文件多选”，在系统文件界面长按图片后选择多张。
2. 如果当前相册没有多选功能，使用“逐张添加（相册兼容）”，可以重复添加。新图追加在原有列表后面，不再替换整批图片。
3. 最多 30 张。缩略图按发送顺序排列，可以逐张移除；清空全部需要确认。图片复制到本应用存储后使用，不依赖长期 URI 权限。
4. 设置间隔并确认开始，每轮完整刷新结束后再等待。此功能是手机持续供能写入，不是手机壳自身的离线轮播。离开、锁屏、断开、停止或刷新失败都会结束任务，不会自动补刷。

系统相册是否支持多选取决于所选提供方，因此本版同时保留分次添加。选图去重覆盖同一批结果中的 ClipData 和单 URI；再次选同一图片属于主动新增一张轮播图。

## 热门图库与服务器

第一次点热门图库时填写完整 HTTPS 网址，也可以在齿轮内更换。当前没有虚构的“官方服务器”，请先部署独立提供的 `suixinyin-gallery-baota-1.0.0.zip`，再填写你自己的域名。支持其他 HTTPS 图库页面，社区功能取决于该网站本身是否提供。

自建图库使用 PHP 8.2+、GD 与 PDO SQLite，宝塔的网站运行目录设为 `/public`。不需要安装 Python、Node 或数据库服务器。详细部署流程见服务器包中的 `README_DEPLOY.md`。配置和数据库放在 public 之外，上传前先把样例配置复制为私有配置并设置管理员密钥及实际域名。

图库支持照片和已处理的四色图片上传，默认立即公开；可将 `auto_approve` 改为 false 开启先审后发。管理页面可审核、下架与删除。图片上限 8 MiB / 1200 万像素，服务端重新编码并生成缩略图；最长边超过 2048 时会缩小。服务端不使用 AI 重绘，也不会自动把普通照片转换成四色。

点赞按匿名访客 Cookie 对同一图片去重。下载由服务器计数，每次主动点击产生一个编号；安卓下载组件接管或重试复用同一编号时不会重复计数。浏览图片和缩略图不计下载。该计数是去重后的下载请求数，不代表独立下载人数或最终保存完成数。

今日、本周、本月排行按 Asia/Shanghai 的自然日、周一开始的自然周、自然月统计下载数；全部作品按累计下载数排序。同次数按累计点赞数和上传时间排序。

App 内下载会交给系统下载管理器。Android 10+ 保存至手机 Download 目录；Android 8/9 保存至应用外部 Download 目录，可从下载记录打开。图片下载后可以再用拍立得选图导入。图库只接受证书有效的 HTTPS，不启用本地文件或 JavaScript 原生桥接。
