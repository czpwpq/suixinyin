# 随心印 2.18-test2 · 卡片显示整理

本版可覆盖安装2.18-test1，保留照片、卡片草稿、已选人物和已获取画像。

- 首页入口、编辑页标题、首页预览和生成卡片中的“二次元生日”统一改为“动漫人物生日”。
- 动漫人物生日卡片不再绘制底部来源、月日核对说明和获取记录；编辑页不再展示有内容时的这段说明。旧缓存也按新规则显示，无需重新获取人物。
- 每日书籍去掉标题上方两条重复的横向装饰线，保留左侧竖向色条、书名、作者及正文。其他卡片的来源和日期显示继续保留。

获取中、网络失败、画像无法显示或没有人物等操作提示仍可见。“查看原文”及内部原始来源和时间记录保留。编辑完成回首页预览，再由首页统一推送；不会自动更新或重新发送。

安装后打开“动漫人物生日”，查看缓存和新获取人物的预览，再打开“每日语录与书籍 → 书籍”检查顶部。确认后手动推送到实屏。

其余功能和内容接口见[2.18使用说明](GUIDE_2_18.md)。Android原生检查只完成编译，实际界面和墨水屏仍需真机确认。
