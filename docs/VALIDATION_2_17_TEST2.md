# 随心印 2.17-test2 验证记录

本版修改范围为四套日历的排版和文字绘制，以及版本信息。没有更换照片算法、卡片编辑流程、完成保护或 NFC 核心。

## 原因与调整

旧版日历部分文字使用常规字重，记录时间一行同时容纳日期、时分、长时区和重复天气来源，原有适配允许将字号缩至14px。此次提高标题、星期、网格数字和天气信息的字号与字重，天气来源和记录时间分行排，长内容按区域省略。

日历仍在552×768物理帧上绘制纯四色像素；逻辑横版为768×552，再作无插值90°旋转。CardFrames保留每个四色索引，PanelType直接打包，日历不进入照片抖动或缩放算法。首页预览缩放只影响手机显示，不改变发送字节。
