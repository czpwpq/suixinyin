# 随心印 2.17-test2 · 日历文字清晰度调整

本版针对手机壳实屏中标题、星期、日期和天气小字偏细、偏小的问题。日历使用系统无衬线粗体和较大字号；长文字按区域省略，不再为了放下一整串时间、时区和来源继续缩成微小字体。

天气来源与记录时间分开排列。联网天气保留 Open-Meteo 署名和服务返回的原始记录日期、时分；画面使用当地时间提示，不在小字中重复长时区名称。完整时间、时区和来源仍保存在卡片草稿与编辑器中。重新生成预览不会把旧记录变成当前时间。

## 安装与使用

1. 覆盖安装 `QPollLab-2.17-test2.apk`，无需卸载或清除数据。
2. 首页打开“日历与天气”，选择原来的版式和日期，调整后点顶部“完成”。也可直接使用自动恢复的日历预览。
3. 在首页核对新的四色预览，再点击“推送到墨水屏”。
4. 保持 NFC 贴稳，等待按钮提示完成，再检查实屏文字。

四套横竖版式、日期标记和完整六行月份继续保留。版式调整会改变最终像素，因此旧日历可作为新内容再次推送；同一画面成功后，完成按钮仍不可点击。确需重复推送，使用顶部“⋯ → 再次推送当前内容 → 确认重发”。

照片、便签、连接方式和 NFC 推送协议延续上一版。日历继续按屏幕原生尺寸生成纯四色像素，不使用照片增强或抖动；横版只作无插值的90°旋转。手机壳小字的最终清晰度仍需实际刷写比较。

建议先测试截图使用的“竖屏 · 大字日期”，重点看顶部短标题、星期、日历数字、Open-Meteo 来源和记录时间；再试横版及六行月份（例如 2020 年 8 月，标记 31 日）。
