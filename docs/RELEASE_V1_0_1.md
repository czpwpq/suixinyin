# 随心印 v1.0.1 · 自动恢复内置连接

修复“第一次激活能传图，关闭 App 再打开后又回到配对流程”的问题。配对身份原本保存在手机中，本版在重新打开时使用已有身份恢复连接。

本次按用户对修复版的试用反馈发布。公开版本为 **v1.0.1**，APK 内部版本保留已测试的 **1.0.1-test1（versionCode 34）**。安装包没有重新构建、改版本名或更换签名。

## 本次修复

- 打开照片、阅读或内置激活页时，自动尝试恢复已有本机连接，无需每次重新输入配对码。
- 优先发现当前本机无线调试端口，上次完整核验成功的连接端口作为回退，支持端口变化。
- 已有连接记录的激活页优先显示“重新连接，无需配对码”；首次配对步骤默认折叠，手动填连接端口的备用入口保留。
- 等待上一服务释放后恢复连接；页面切换保留短暂交接时间。离开 App、切换后端或明确停止时结束恢复，避免反复尝试。
- 普通断网、端口失效不会删除身份。旧缓存端口的 TLS 错误不会直接要求重配；当前服务确实拒绝身份且候选耗尽后才提示重新配对。
- 恢复后更新首页连接状态，清除旧推图请求；仍由用户手动推送，不会因恢复连接自动传图或开始阅读刷写。

保留已有照片编辑、四色处理、便签、日历天气、每日内容、动漫人物生日、TXT 阅读和音量翻页功能。NFC 传输、图像算法及原厂全局刷新核心保持不变；本版不增加局部刷新。

## 升级与使用

1. 直接覆盖安装本 Release 的 APK，**不要先卸载**，保留原配对、草稿和书库。
2. 保持系统无线调试开启，重开 App，等待首页从“连接中”变为“已连接”，再手动推送。
3. 首次从 v1.0.0 覆盖时，旧版没有保存连接端口。如果系统自动发现不可用，只需在“内置激活 → ③ 手动连接端口（备用）”填写当前连接端口并成功连接一次；通常无需重配。

手机重启或系统关闭无线调试后，仍须先在系统中重新开启；系统撤销配对或清除 App 数据后仍需重新配对。明确停止内置服务后，可手动点重新连接恢复。详见[使用说明](GUIDE_1_0_1_TEST1.md)。
