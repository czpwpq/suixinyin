# 随心印 2.16-test1 · 照片工作室

本版按照 miaomo 的照片工作室和编辑器移植交互及本地图像处理，保留随心印已有的 Shizuku 身份校验和 NFC 推送后端。主界面为照片、设备、日志三个页签；热门图库及服务器上传入口暂时撤下。

## 照片

1. 点击选择照片。默认进入构图编辑；也可从右上角更多菜单从文件选择或体验测试图。
2. 编辑器支持横竖向画布、旋转、镜像、填满或完整显示、拖动及双指缩放。撤销/重做可恢复构图、文字和相框变化；取消编辑不提交本次修改。
3. 文字支持多行、字体、字号、颜色、底色、描边、角度、对齐、拖动、缩放、复制、删除及置顶，最多 20 个图层。
4. 相框包括无框、留白、细线、双线、拍立得和胶片，可改颜色和宽度。点击完成后重新生成最终四色画面。
5. 对比按钮切换合成原图和最终四色；在原图状态点击推送会先切回四色供核对，不立即发送。右上角更多可保存四色 PNG。

照片默认使用参考项目同一套 InkSight 增强、Lanczos 适配和 Atkinson 四色处理，色板为黑、白、暖黄和深红。相框和文字先合成，再统一进入四色处理。编辑过程保留原图，最近一张照片和编辑草稿存于 App 私有目录，重新打开 App 时只恢复预览，不自动发送。更换照片会开始新草稿。

## 推送

先在设备页确认实物 A0/A1。连接和授权沿用此前便捷版；同一包名和签名可覆盖安装。照片处理不接入参考项目的其他 NFC 通道，不自动更换手机配置或推送协议。

最终预览核对后点推送。底部按钮和状态固定可见，显示连接、传输百分比、刷屏和停止状态。图片传输到 100% 后仍需贴合供能，等刷新周期结束并目视检查画面。停止请求发出后等待当前通信结束，失败由用户再次点击重试，不自动重放。

## 日历与天气

照片页有日历与天气入口。保留两种竖版和两种横版日历、月份/标记日期、标题、四色强调色，以及黄色天气区域。搜索城市后可获取天气，也可手动输入城市、天气和温度。

天气仅在主动查询时访问 Open-Meteo，不需要定位权限；网络失败可继续手动填写。天气是查询时的快照；无独立供电的 NFC 屏幕不会自行更新。便签入口继续提供纯文字卡片。

## 设备与日志

设备页可选择 A0/A1、进入连接授权和原有传输参数。日志页可查看、复制和保存本地运行文字日志。保存 PNG 或日志均通过系统文件选择器，由用户决定位置。
