# 随心印 2.17-test1 · 完成保护与卡片创作

本版解决完成后误点按钮再次启动 NFC 的问题，并让日历天气、便签与照片使用同一个首页推送入口。

## 刷新完成后

推送成功后，首页按钮显示完成并保持不可点击。再次点击、切换页面、恢复前台或仅重新生成相同内容，都不应重新发送。

确实需要把当前内容再推一次时，打开顶部“⋯”，选择“再次推送当前内容”，再点“确认重发”。最终发送像素或屏幕类型实际变化后，首页会显示新的待推送预览；失败后可主动重试。应用不会自动重发刷新命令。

## 日历、天气和便签

1. 在首页选择“日历与天气”或“便签”。
2. 在与照片编辑器相同风格的底部工具区调整内容、日历版式或便签样式。天气可手动填写；只有主动查询天气才联网。
3. 点击编辑器的“完成”，返回首页查看最终四色预览。完成编辑不会启动 NFC。
4. 核对预览，再点击首页推送按钮。所有内容都从首页这一个入口发送。

取消编辑会保留首页原来的照片或卡片，不替换正在核对的内容。更改文字、日期、天气或样式后需重新点击完成，首页才接受新的卡片。日历保留四种横竖版式；便签支持四色文字与底色、字号、粗体和描边。

## 传输与停止

首页底部只保留推送按钮，按钮文字显示连接、包传输百分比、屏幕刷新、停止、完成或失败状态。100% 表示图像包已传完；仍需保持 NFC 贴合，等待刷新和通信清理结束，再目视检查屏幕。

发送中需要中止时，打开顶部“⋯”并选择“停止本次推送”，等待实际结束。切到后台也会请求停止；恢复前台不会自动继续刷写。

设备授权、连接和 A0/A1 选择仍在设备页。照片 InkSight 处理、连接方式及 NFC 协议延续上一版；图像在本机处理。本版的卡片编辑与完成保护仍需在手机上执行验收，主机或编译检查不能替代实屏测试。
